# 720-script-writer

סקיל שממיר תוכן מקובץ Word ("תבנית פיתוח תוכן ליעד") לשקפי PPTX בתסריט 720/methodica קיים —
כללי לכל מקצוע/יחידה, לא ספציפי לפרויקט אחד.

## עקרון מרכזי
הסקיל **תמיד** משכפל שקפים מקובץ ספריית-תבניות ייעודי (`תבנית לתסריט.pptx`) — לא בונה צורות
מאפס, ולא מחפש דוגמאות בתוך התסריט הנבנה עצמו. אם אין תבנית מתאימה — הוא עוצר ושואל.

## מקור הידע
נבנה על סמך עבודה בפועל (לא תיאוריה): בניית סעיפים א/ב/ג של שאלה 1 בתסריט 4.2 (מתמטיקה,
אחוזים), כולל כל התיקונים שהמשתמש נתן בזמן אמת. כל כלל ב-`references/` מגובה בדוגמה קונקרטית.

## מבנה
```
SKILL.md                          תהליך העבודה המלא (6 שלבים + שער עצירה)
scripts/pptx_slide_ops.py         שכפול שקפים (בתוך קובץ / בין קבצים), מקטעים, טקסט עשיר
references/
  word-doc-schema.md              איך לפרש את טבלת ה-Word
  section-structure.md            מקטע = PowerPoint Section, מנגנון XML
  template-catalog.md             קטלוג תבניות המסך + כללי הפקה גורפים
  content-style-rules.md          ניסוח/עיצוב: אות סעיף, בולד+סגול, יישור משוב...
  feedback-bank.md                32 פתיחי-משוב שליליים לבחירה אקראית
  metacognition-bank.md           שאלות פיגום מטה-קוגניטיביות
  construction-checklist.md       תקלות ידועות + בדיקות אימות
```

## מגבלות ידועות
- קטלוג התבניות (`template-catalog.md`) מבוסס על קריאה חד-פעמית של `תבנית לתסריט.pptx`,
  משלימה בשם פיגמה שאושר בפועל (`DragAndDropQuestion`, שקפים 51–54). שאר השמות טרם אומתו מול
  פיגמה בפועל מעבר לקריאת הערות ההפקה בקובץ עצמו.
- שילובים אד-הוק שנבנו ב-4.2 (dropdown-per-cell בטבלת ערך משולש) **אין להם** תבנית מקבילה
  בספריית התבניות — ל"השלמה מתוך מחסן" מסוג התאמה/מיון, `DragAndDropQuestion` הוא כנראה
  הפתרון הנכון (ולא dropdown), אך יש לאשר עם המשתמש בכל מקרה קונקרטי, לא להניח אוטומטית.
- לא נבדק עדיין על שאלה מרובת-תמונות/מדיה מורכבת יותר מתמונה בודדת.
